# 页面交互与动效优化

沿用暖黄、纸白和深棕配色。触控反馈约 100ms、弹层退出 180ms、内容进入 260ms，动画服务于状态变化，金额始终展示真实值。

## 本轮改动

- 首页、统计、我的和编辑页增加内容进入效果；其他功能页卡片首次渲染淡入。
- 首页月份、成员、日历以及搜索结果切换时重播局部内容过渡；同步刷新不反复播放整页动画。
- 首页更多、账本切换，统计日期和海报，我的资料/帮助/关于，编辑账户选择均支持退出过渡。
- 退出阶段保留遮罩，结束后恢复底部导航；导航动作等待面板退场，快速重复点击只执行一次。
- 页面隐藏或销毁时清除退出计时器；关闭中重新打开取消旧回调，避免过时回调造成跳转或关闭新弹层。
- 各功能页可点击行、筛选、分类和数字键盘加入微信原生 hover 反馈；分类和分段控件增加选中态颜色/边框过渡。
- 底部导航增加按压、选中状态过渡；当前页重复点击不重新跳转，记一笔入口增加请求期间的连点保护。
- 进度条宽度平滑变化，图表提示淡入；首页金色主卡首次展示单次微光，无循环装饰动画。
- 统计切换合并待绘制任务，隐藏页面取消绘制，异步查询返回时拒绝旧绘制任务。
- 遵循系统 `prefers-reduced-motion`，关闭位移/缩放及装饰动画。未给整个页面根容器施加变换，避免影响固定弹层、键盘和导航定位。

## 验证

- `npm test`：60 项通过。
- `npm run test:ui`：30 项通过，其中新增 11 项覆盖动效状态、关闭重开、延迟导航、连点保护与图表绘制清理。
- `npm run test:compile`：微信官方 `wcc` 编译全部 19 个 WXML，`wcsc` 编译全部 21 个 WXSS，通过。
- JavaScript 语法检查及 `git diff --check` 通过。
- 开发者工具重新编译恢复首页，调试错误数为 0；原生自动化的点击及轻微拖动未触发模拟器交互，因此未确认动画流畅度或真机表现。
