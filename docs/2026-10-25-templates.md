# 常用记账模板

入口：首页「快速记一笔 → 常用模板」、「我的 → 常用模板」；账单详情可「存为常用模板」。

模板按账本保存，每个账本最多 50 个。支持支出、收入、转账及类型筛选。新建和编辑复用记账表单，保存前输入名称；只保存金额、分类、账户和备注，不产生账单。使用模板预填今天的日期，确认保存后才入账，日期和其他字段仍可调整。

分类失效时要求重新选择；账户失效时清除并提醒，转账必须重新确认有效的两个账户。取消命名保留草稿，离开有修改的表单沿用未保存提醒。编辑、删除模板不改变历史账单。

客户端和后端增加 templates 配置字段。缺省字段保留现有模板，较新显式空数组删除；旧配置不能复活模板。配置版本严格递增，周期记账不会把版本降回系统时间。后端增加幂等 templates_json 数据库迁移，服务端代码尚未部署；跨设备模板同步需部署更新后的 server/server.js。

验证：npm test、npm run test:ui、npm run test:compile；模板专属 10 项测试，隔离 HTTP 后端覆盖双设备同步与旧客户端兼容。独立代码审查未发现重大或中度问题。

模拟器已确认首页入口、管理空状态、统一暖黄布局、新建模板表单、金额键盘、中文命名和取消命名保留金额。未在实际账本保存测试模板或账单。命名取消后的退出确认未完成可靠实测；该路径有自动化测试，仍需真机补测。
