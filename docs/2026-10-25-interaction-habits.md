# 高频交互整理

本轮围绕用户反馈“很多交互不符合用户习惯”调整已有操作，不新增财务功能。

## 记一笔

- 分类区仅保留稳定的分类网格，去掉同屏重复分类的最近使用条。
- 日期、账户和备注固定在数字键盘上方，分类滚动时仍可操作。
- 页面顶部为返回与类型切换，统一使用底部「保存」按钮。
- 连续记账通过明确开关选择，保存按钮相应显示「保存并继续」；编辑账单与模板不提供连续记账。
- 普通保存写入后立即返回原页面，仍阻止快速连点重复入账。
- 输入备注时收起自定义数字键盘，并按原生键盘高度调整可用区域；完成或失焦后恢复，保留金额与备注。键盘高度事件只用于避让，不改变输入焦点，避免快速重新输入时被旧关闭事件打断。
- 长按退格清空金额与计算，不改变分类、账户和备注。
- 账户弹层支持滚动，明确标记当前选择。
- 转账自动选择不同的两个账户；误触同一转入账户时保留原选择并提示。

## 查账

- 首页「全部 N 笔」承接当前月份与成员筛选，立即显示对应账单。
- 「账单明细」打开即查询，筛选默认折叠，结果优先展示。
- 可展开筛选并「查看结果」，错误条件保留展开以便修正。
- 关键词清空保留其他条件；重置条件恢复全量结果。
- 搜索提交收起键盘；从详情返回保留条件并更新结果；统计分类钻取保留原条件。

## 模板

点卡片直接预填记账。编辑和删除收进卡片的「更多」，点击更多不会触发卡片使用；删除继续要求确认，取消不改动模板或历史账单。

## 入口与按钮规则

根据用户进一步反馈「页面入口多，按钮行为不一致」继续整理：

- 首页更多由 10 项收为「查找账单 / 切换日历或列表 / 功能管理」3 项。查找账单覆盖全时段，最近账单的「全部 N 笔」继续保留当前月份与成员条件。
- 「功能管理」等菜单退场后切换到「我的」，退场期间连点只执行一次，恢复底部导航后再进入目的页。
- 「我的」按记账管理、财务计划、数据工具分组；常用模板与周期记账都在记账管理中。帮助与关于收为页尾文本操作。
- 成员管理迁到账本管理里的共享账本区域。账户转账仍可从记账表单或资产页进入，原能力均可到达。
- 原「云同步」箭头行改为「同步与设置」并打开设置；顶部账号状态也统一进入该页，不再根据账号状态隐式触发不同动作。手动同步使用设置页里的「立即同步」按钮。
- 我的页面跳转期间阻止重复打开；导航失败可重试，返回后可再次打开。
- 详情只展示「更多 / 编辑账单」，再记一笔、存为常用模板和删除放在更多内。再记仍只预填，删除仍二次确认并进入回收站；菜单打开后记录被删除时，不得继续操作旧数据。
- 帮助说明同步到现有入口，去掉普通用户流程中的服务器地址。

## 验证

模拟器已实际检查：记账页面分类和固定操作区渲染、备注输入中文完整保留、聚焦备注时数字键盘让出空间、完成后数字键盘恢复、有草稿时返回要求确认。开发工具未显示真实手机原生软键盘，原生键盘高度避让仍需真机验证。

后续已完成模拟器点击检查：首页工具面板仅展示三个入口；「功能管理」退场后进入「我的」并恢复底部导航；账本管理中的成员管理可打开；顶部账号状态进入设置且可正常返回；日历与列表可切换。首页「全部 19 笔」保留当前月份，详情更多展示再记、模板与删除，取消后原账单金额与备注不变，从详情返回仍保留月份筛选。首页工具面板的「查找账单」则显示「全部时间 · 全部类型」，退出后返回首页。全过程未保存、删除或修改真实财务数据。

仍需真机或专项触控检查的项目：原生软键盘高度避让、长账户列表滚动、小屏分类区以及模板更多菜单。筛选折叠状态已在模拟器确认；这些行为的自动化测试不能替代真机触控和键盘检查。
