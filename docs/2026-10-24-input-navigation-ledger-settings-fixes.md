# 输入框、导航、账本同步和设置页修复

## 修改内容

- 为单行输入框设置明确高度、横向内边距和正常行高，避免原生 input 在 border-box 下被纵向 padding 挤压。覆盖账本弹窗、预算、资产、周期记账、搜索、分类、备注和昵称。
- 昵称编辑期间保留输入草稿，数据库刷新不会覆盖正在输入的内容；头像使用独立圆形裁切容器。
- 底部导航使用统一线宽的本地 PNG 图标，选中态沿用暖黄配色。生成源保存在 `design/generate-navigation-icons.py`。
- 「我的」齿轮进入独立设置页，提供资料编辑、同步状态、手动同步和数据说明。
- 登录后先应用云端快照，再推送本机数据；仅丢弃尚未使用、配置仍为默认值且未同步的自动空账本，保留手动创建或使用过的账本。
- 账本移除按账号同步。离线移除保留待发送状态，服务端确认后停止重发；旧设备回推不能让已移除账本复活。其他共享成员不受影响，主动凭邀请码重新加入可恢复访问。
- 云端快照落入本机数据库时不再触发下一轮防抖同步，避免持续刷新。

## 更新要求

客户端和 `server/server.js` 需要一起更新。服务端启动时自动创建 `removed_ledgers` 表，原有账本和记录不需要清空。现网升级沿用 `server/DEPLOY.md` 的升级流程；本次只修改和验证工作区代码，未发布小程序或部署服务器。

旧版客户端保存的本机隐藏列表会自动转为待同步移除操作。对于已清除本机隐藏信息、现在再次可见的历史重复账本，无法可靠判断用户删除意图，因此不自动批量删除。

删除最后一个账本后仍保留一个空白账本供继续记账。
