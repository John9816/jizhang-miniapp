# 账单误删恢复

入口：我的 → 设置 → 数据管理 → 账单回收站。

本轮沿用暖黄、白色卡片与深棕文本；搜索框固定 96rpx 高度，筛选、恢复及清空搜索保留足够触控范围。页面提供全部账本/单账本筛选、关键词搜索及每次 30 条的分页加载。

恢复使用原记录 ID、原金额、日期、分类、备注及账户关联，不创建新账单。恢复后重新计入收支、预算与账户余额；转账依旧不计入收入支出。记录生成递增版本并标记待同步，旧删除请求的确认和旧快照不能覆盖本机恢复。

边界：

- 已移除账本不列入回收站，也不因恢复操作重新加入。
- 转账任一原账户不可用时禁止恢复；普通账单保留历史账户关联，并提示恢复后可编辑账户。
- 同账本已有相同来源与交易单号的活跃账单时禁止重复恢复；未有稳定交易单号的记录不做模糊拦截。
- 确认操作前重新验证最新状态。取消不写入数据，多次恢复不产生副本。
- 页面只展示已同步或保存在本机的删除记录，不自动清理；这不是完整备份恢复功能，也不能恢复已经被移除的账本。
- 共享账本恢复操作沿用原有成员同步机制，会传播给其他成员。

验证：新增 9 项内存存储流程测试及 1 项隔离 HTTP 后端恢复传播测试，覆盖收支与资产、转账、失效账本/账户、导入重复、分页与搜索、重启和同步竞态。模拟器确认设置入口可达、空状态与搜索框完整显示；实际数据没有删除记录，未为了测试新增、删除或恢复用户真实账单。有记录时的逻辑由隔离测试验证，真机和生产服务多设备验收仍待进行。

代码审查发现分页前校验全部墓碑会造成大量记录下的卡顿，已改为筛选并分页后检查可见记录。

后续优先级：完整备份与校验恢复、常用账单模板、退款/报销业务模型、预算历史与结转、信用卡账单和还款管理。
